# 0004. G3 에코 t_score의 수치 동치 정의 정확화 (비교 완화 아님)

상태: 채택 (2026-09-01, 커밋 64a9364)

## 맥락
초기 실험용 소형 로컬 모델(기록에서 제외) 실측에서 척도 카드가 프로파일당 11블록 폴백됐다. 위반 로그를 보니 모델이 `t_score`를 문자열 `"57"`로 에코했고,
G3 에코 대조가 이를 위조로 판정했다.
## 결정
에코 `t_score`의 동치 정의를 "정수이거나, 정수로만 이뤄진 문자열"로 정확화한다 (`src/guardrails.py` `_canonical_t`). 값 비교는 그대로 정확 일치이고,
`band` 에코와 본문 수치 대조 축은 바꾸지 않는다. `bool`은 제외한다 (`True == 1` 함정).
## 근거
`'57'`과 `57`은 같은 수치다. 유사도 허용이 아니라 동치 정의의 정정이며, `"58"`이나 `"57점 정도"`는 여전히 위반이다.
## 대안
비교 완화(±1 허용 등)는 수치 위조 검출이라는 G3의 목적과 충돌해 기각. 프롬프트로 정수 출력을 강제하는 방법은 초기 실험용 소형 로컬 모델에서 지켜지지 않았고
검증기 대신 모델에 기대는 방식이라 기각.
## 결과
같은 모델·프로파일에서 폴백 11 → 0 (README '--api 실측' 관찰 2). 검증기의 동치 정의 하나가 로컬 모델 활용성을 좌우한다는 교훈이 실측 절에 기록됐다.
