# 0003. SEM 대칭 밴드 채택, 비대칭 완화안 기각

상태: 채택 (2026-09-01)

## 맥락
종형곡선 위 아이 위치 마커에 측정 불확실성을 어떻게 그릴지. 그래픽은 텍스트보다 판정처럼 읽히므로
`src/renderer.py`는 "전부 숫자에서 기계적으로 생성, 확률 모델 개입 없음"을 원칙으로 한다.
## 결정
SEM 대칭 밴드. SEM = SD x sqrt(1 - 신뢰도)이며 신뢰도 예시값 .84 기준 4.0T(`DEFAULT_SEM`). 밴드는 `t_score ± SEM`으로 좌우 동일하고,
예시값임을 화면에 표기한다 (`src/report_html.py` `SEM_NOTE`).
## 근거
표준오차 정의에서 기계적으로 나오는 구간이라 근거를 한 문장으로 설명할 수 있고, 척도별 신뢰도 계수만 바꾸면 실제 서비스로 옮겨진다. 렌더러가 판정을 만들지 않는다.
## 대안
비대칭 완화안 - 밴드를 한쪽으로 넓혀 경계 근처 점수의 인상을 완화하는 안. 수치에서 유도되지 않는 시각적 판정이 되므로 기각
(README '사용한 AI 도구' 표의 사람 결정 항목에 기록).
## 결과
`bell_curve_svg(t_score, criteria, sem=DEFAULT_SEM)`. 신뢰도 계수가 예시값이라는 점은 README '알려진 한계'에 남아 있다.
