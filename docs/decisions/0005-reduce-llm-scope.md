# 0005. LLM 범위 축소: 척도별 해설은 고정 문구, LLM은 인용이 필요한 곳만

상태: 채택 (2026-09-02)

## 맥락
G7~G9 추가와 프롬프트 개정 후 초기 실험용 소형 로컬 모델(기록에서 제외) 재측정에서 최종 출력 결함은 0이 됐지만 폴백이 p2 14/17, p5a 12/17 블록,
척도 카드는 11/11 폴백이었다 (아래 실측 요약). 원인은 위반 로그에 있다: 모델이 "사람이 읽는 문장에 코드 금지"를 JSON 필드에까지 적용해 `scale_id`에 한국어 척도명,
`band` 에코에 "정상/준임상", `source_scale`에 null을 넣었다 (G4x8, G3 에코 x11, G5 항목 수).
## 결정
척도 카드 해설은 LLM이 아니라 척도x밴드 고정 문구가 맡는다. LLM은 보호자의 말을 인용해야 하는 곳 - 연결 문단, 질문, 관찰 포인트, 상담사 사전 요약 - 에만 쓴다.
## 근거
척도 정의와 밴드의 의미는 입력마다 달라지지 않아 생성할 이유가 없고, 생성하면 검증과 폴백 비용만 든다. 이 기획의 척추(보호자 표현 인용, 품질 지표 ii)는 질문·관찰에 있다.
## 대안
프롬프트 예시 보강만으로 대응(모델이 바뀌면 다시 실패할 수 있음), 더 큰 모델로 교체(로컬·비용 조건과 충돌)는 기각.
## 결과
척도 카드가 결정론 영역으로 이동해 재생성·폴백 대상에서 빠지고, explain 태스크의 LLM 출력 스키마와 G3 에코 대조 범위가 줄어든다.
실측 표의 폴백 지표는 새 구조에서 다시 재야 비교할 수 있다. 결정 경위는 아래 실측 요약에 남기고 구현은 별도 변경으로 들어간다.
## 실측 요약 (초기 실험용 소형 로컬 모델, 기록에서 제외 - 모델명·크기 비공개)
- 에코 오검출: 모델이 `t_score`를 문자열 `"57"`로 에코하자 G3가 위조로 판정해 프로파일당 11블록이 폴백됐다. 동치 정의 정확화(ADR 0004) 후 폴백 0~1.
- G7~G9 추가 전: G1~G6을 전부 통과한 최종 출력에 코드 누출 9건, 정상 척도 질문 4건, 라벨 위반 11건(p2)이 실려 있었다. 추가 후 결함은 0이 됐지만
  모델이 코드 금지를 JSON 필드에까지 적용해 폴백이 p2 14/17, p5a 12/17로 급증했고 척도 카드는 11/11 폴백이었다.
- 범위 축소 후(LLM 블록 5개): 두 프로파일 모두 폴백 0/5, 코드 누출·정상 척도 근거·라벨 위반 0. 보호자 표현 반영률(항목)은 p2 56 → 78%, p5a 33 → 75%로
  올랐다. 그 사이에 질문 예시 2 → 5개 보강과 G10(예시 오염: 다른 프로파일의 예시 문구를 보호자의 말처럼 인용) 추가가 있었다.
- 이 모델은 성능이 낮아 이후 기록에서 뺐다. 현행 실측(gemma4:12b·qwen3.8:27b·gemma4:31b, GPU 서버)은 README "--api 실측" 절에 있다.
