# 0005. LLM 범위 축소: 척도별 해설은 고정 문구, LLM은 인용이 필요한 곳만

상태: 채택 (2026-09-02)

## 맥락
G7~G9 추가와 프롬프트 개정 후 exaone3.5:7.8b 재측정에서 최종 출력 결함은 0이 됐지만 폴백이 p2 14/17, p5a 12/17 블록, 척도 카드는 11/11 폴백이었다
(README 재측정 표). 원인은 위반 로그에 있다: 모델이 "사람이 읽는 문장에 코드 금지"를 JSON 필드에까지 적용해 `scale_id`에 한국어 척도명,
`band` 에코에 "정상/준임상", `source_scale`에 null을 넣었다 (G4x8, G3 에코 x11, G5 항목 수).
## 결정
척도 카드 해설은 LLM이 아니라 척도x밴드 고정 문구가 맡는다. LLM은 보호자의 말을 인용해야 하는 곳 - 연결 문단, 질문, 관찰 포인트, 상담사 사전 요약 - 에만 쓴다.
## 근거
척도 정의와 밴드의 의미는 입력마다 달라지지 않아 생성할 이유가 없고, 생성하면 검증과 폴백 비용만 든다. 이 기획의 척추(보호자 표현 인용, 품질 지표 ii)는 질문·관찰에 있다.
## 대안
프롬프트 예시 보강만으로 대응(모델이 바뀌면 다시 실패할 수 있음), 더 큰 모델로 교체(로컬·비용 조건과 충돌)는 기각.
## 결과
척도 카드가 결정론 영역으로 이동해 재생성·폴백 대상에서 빠지고, explain 태스크의 LLM 출력 스키마와 G3 에코 대조 범위가 줄어든다.
실측 표의 폴백 지표는 새 구조에서 다시 재야 비교할 수 있다. 결정은 README 재측정 절에 기록됐고 구현은 별도 변경으로 들어간다.
